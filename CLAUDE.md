# CLAUDE.md

## Conventions

- Always use C++23.
- Avoid unnecessary comments.
- Do not build after every change. Only build when explicitly asked; when asked, fix any errors that come up.
- Never use Co-Authored-By tag in commits; instead, use Assisted-By: <Model>.
- Use branch names in the format "claude/<branch>". Typically, you'll want to name the branch after the feature.
